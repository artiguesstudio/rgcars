Privacidad

Política de privacidad

En RG Cars TDF utilizamos la información que ingresás en formularios y canales de contacto para responder consultas, gestionar solicitudes comerciales y ordenar el seguimiento operativo.

1. Qué datos podemos solicitar

Podemos recibir nombre, teléfono, correo electrónico, datos de vehículos, intereses de búsqueda, observaciones comerciales, datos de financiación y archivos o imágenes que el usuario comparta voluntariamente. En búsquedas laborales también podemos solicitar edad, estado civil, cantidad de hijos, disponibilidad de carnet de conducir, experiencia y currículum vitae.

2. Para qué usamos la información

Los datos se utilizan para responder consultas, coordinar contacto comercial, evaluar operaciones, gestionar servicios vinculados al automotor y mejorar la atención. Los datos de postulantes se utilizan exclusivamente para recibir, revisar y contactar candidaturas laborales de RG Cars TDF. Para ordenar la revisión puede calcularse una afinidad preliminar basada únicamente en años de experiencia en ventas y experiencia automotriz. La edad, el estado civil y la cantidad de hijos no intervienen en ese cálculo, que tampoco acepta ni descarta candidaturas automáticamente.

3. Conservación y acceso

Los datos pueden conservarse durante el tiempo necesario para gestionar la consulta, la operación, el seguimiento comercial o el proceso de selección relacionado. Los CV se almacenan en un espacio privado y su acceso queda limitado al personal autorizado.

4. Medición, atribución y preferencias

El sitio puede registrar de forma propia páginas visitadas, origen de campaña, parámetros UTM, identificadores de clic publicitario, sesión, vehículo consultado y acciones comerciales. Esta información se utiliza para atribuir consultas y evaluar el funcionamiento del sitio. Los datos de contacto ingresados en formularios se conservan en el CRM y no se envían a GA4, Meta Pixel ni dataLayer.

Si la persona habilita medición publicitaria, Meta Conversions API puede recibir desde el servidor versiones normalizadas y protegidas con SHA-256 del email o teléfono para asociar una conversión. Esos datos no se incorporan al código público ni a los registros técnicos de entrega.

Las etiquetas opcionales de Google y Meta permanecen desactivadas hasta que el visitante elige habilitar la categoría correspondiente. La elección se guarda en el navegador y puede modificarse en cualquier momento.

5. Proveedores tecnológicos

Cuando estén configurados y exista consentimiento, pueden utilizarse Google Analytics 4, Google Tag Manager, Google Ads, Meta Pixel y Meta Conversions API para medición y atribución. Supabase se utiliza para base de datos, autenticación y funciones server-side. La disponibilidad de estas integraciones depende de la configuración vigente.

6. Derechos del titular

El titular de los datos puede solicitar acceso, actualización o supresión de la información mediante los canales de contacto publicados en este sitio.

7. Organismo de referencia

Para conocer más sobre protección de datos personales y derechos vinculados, podés consultar la Agencia de Acceso a la Información Pública (AAIP).
